# Citrus Twist PLAnt Kit
This design was made and submitted to the [Repeat Robotics Open PLAnt Challenge](https://repeat-robotics.com/blogs/b/repeat-open-plant-challenge).  All electronics and hardware used to construct this kit can be found in the [Repeat Robotics Open PLAnt Bundle](https://repeat-robotics.com/products/open-plant-bundle), and all other parts are designed to be 3D printed from PLA+.
