# Citrus Twist Extras
This folder is dedicated to other bits and pieces that I thought would make for fun extras or used personally for testing.  Each item in this folder is described in the list below:

1. **weapon_ring_base.step:** This is a version of the weapon ring that has no teeth or impactors, just the gear and sliding surfaces.  It's a perfect place to start learning CAD by designing your own impactors!  Asymmetric, sawblade, you can do it!  Go wild!
2. **upper_core_base.step:** This is a version of the "upper core" part that has no swirl or pattern on it.  Design your own pattern and embed it into the surface to make the robot truly your own!
3. **display_stand.step:** Proud of your build and want to show it off on a shelf?  This display stand is designed to help your robot sit upright.
4. **2822 V2 Motor:** The V2 2822 motor has different mounting geometry and patterns.  This folder contains a drive gear and lower core file compatible with the 2822 V2 motor.  All other parts can be reused for this mod.
5. **Cast Wheels:** Don't have Lego wheels or want to upgrade to cast urethane wheels?  This folder contains a slightly modified hub, interface part for gyroid infill, and a mold.
