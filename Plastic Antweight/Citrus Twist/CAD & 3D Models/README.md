# CAD & 3D Models
Welcome to the repository for Citrus Twist PLAnt kit!  

To get started, head to the [Basic Parts](https://github.com/anonymous-k1wi/Robot-CAD-Files/tree/main/Plastic%20Antweight/Citrus%20Twist/CAD%20%26%203D%20Models/Basic%20Parts) folder to find the robot assembly file, separate .step files for each component, and a .3mf file with recommended print settings.

For alternate parts and upgrades, open to the Extras folder to find cast wheel setups, files for the Mk2 2822 motor, a toothless weapon for you to design yourself, a design-less topplate, and more!
